海研分析 · 设置中心升级

新增顶部导航：
⚙ 设置

设置页包含：

1. 账户与访问
- 当前默认不是实际账户体系
- 点击“登录”后显示：
  “目前已使用游客模式登录”
- 可以退出游客模式
- 不连接真实用户名、密码、数据库或身份认证系统

2. 管理我的科研模板
- 查看本地/当前环境保存的科研模板
- 重命名模板
- 勾选确认后删除模板
- 公网 Streamlit Cloud 文件存储仍不保证永久持久化

3. 语言与显示
- 中文 / English
- 与顶部语言设置同步

4. API配置
- 提供 API 服务商、模型名称、API Key 输入区域
- 当前仅作为产品设置界面展示
- 点击保存不会把 API Key 写入磁盘，也不会自动启用真实 API
- 即使不配置 API，平台仍可以继续使用现有本地/规则解析能力

5. 数据与隐私
- 说明模拟数据、游客模式和真实医院部署边界

6. 系统信息
- 当前版本
- 运行方式
- 数据模式

使用：
- 覆盖 app.py
- 同时覆盖 template_store.py
- research_agent.py / concept_resolver.py 可继续使用本升级包内版本
- 本地运行：
  py -m streamlit run app.py

GitHub：
- 将 app.py 和 template_store.py 更新到仓库
- Commit changes
- Streamlit Cloud 自动重新部署
